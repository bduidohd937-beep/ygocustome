# P1-01 — 이소바르 실행 기준선

기존 `5e45c71`은 로컬 bundle 및 원격 `feat/duelmind-core-v2`에 보존했다. 미공개 커밋은 1개, 변경 파일 8개의 이력과 비밀키/토큰 패턴을 검수했다. 민감정보 패턴 발견 0건. main 및 다른 worktree는 변경하지 않았다.

## 선택한 기준

`isobar-v2.0.2-49a0643`, 원본 커밋 `49a0643ca322cc6ea393631c59190c20a0e82a28`을 현재 배포된 **실행 규칙 snapshot**으로 선택한다. 16장 개별 Lua는 설치본과 바이트 일치하고 CDB는 datas/texts의 모든 열(선택 문자열 16개 포함)이 일치한다. 공용 `isobar.lua`는 설치본 CRLF, Git 원본 LF의 줄바꿈만 다르다. helper의 내용 일치와 raw hash 일치를 구분한다.

카드 원문과 Lua의 의미 동등성을 새로 승인하거나 보장하는 결정이 아니다. 기존 승인·배포 계보를 고정하여 AI와 테스트 게임이 같은 Lua를 쓰도록 하는 선택이다. 원문/효과 변경은 하지 않았다. legacy 13종 root assets는 원래 회귀 기준으로 그대로 남겼으며 신규 runtime은 `duelmind/assets/isobar-v2.0.2`의 16종을 명시적으로 사용한다.

## 카드별 대조

`comparison.json`에 16종의 구/신 이름·전체 CDB 데이터·효과 설명·선택 문자열·등록 코드·Executor/Python ID 참조 여부와 검토 메모를 수록했다. 214 시러스, 215 님버스, 216 폭풍경계는 기존 AI가 참조했으나 legacy CDB/Lua에는 없었다. 신 baseline은 16종 전체와 helper·원문 TXT의 hash를 manifest에 고정한다.

주요 변경은 아르젠의 묘지 소환, 볼트의 특수소환/기상변경, 솔의 묘지 준비/회수, 제피르·호크·바스티온의 자원 처리, 템페스트의 소재/quick·대상 분기, 관측소의 서치/세트, 기압전선의 기상별 효과, 관측일지의 소생이다. 자세한 차이는 카드 ID로 비교 자료를 조회한다.

## 원문·현재 Lua의 미해결 차이 — 그대로 보존

- 201: 원문 이탈시 제외 적용 범위와 Lua의 묘지 소생 한정 적용 차이.
- 204: 원문은 동일 카드 제외 덱 묘지 보내기, Lua 필터는 동일 ID를 제외하지 않음.
- 205: 원문 몬스터 회수/선택 적용과 Lua의 이소바르 카드 전반 선택 차이.
- 206: 원문 소재 제거시 덱에서 몬스터 묘지 보내기, Lua는 묘지 자원을 덱으로 회수.
- 208: 원문 발동 무효+별도 후속, Lua `NegateEffect`+동일 operation 회수.
- 211: 원문 상대 효과 파괴 내성/몬스터 회수와 Lua의 범위 차이.
- 214: 관측소 없는 상황의 target 검사와 실제 선택 필터가 일치하는지 확인 필요.
- 215: 부여 효과의 소환 턴 제한이 Lua에 없고 발동 무효 문구와 `NegateEffect` 차이.
- 216: optional 대상 문구와 발동시 대상 필수 여부, 묘지 턴 플래그의 실제 타이밍 확인 필요.

이는 정적 검토 결과이며 실제 코어 검증은 후속 runtime 단계에서 별도 기록한다. 이 차이를 AI가 임의로 보정하거나 원문을 실행 규칙으로 추정하지 않는다.

## AI 연결

V1 및 baseline 미지정 기존 요청은 정책과 응답을 보존한다. 새 baseline을 명시한 요청은 동일 카드별 휴리스틱을 사용하되 오래된 효과 라벨·verified 상수 annotation을 규칙 근거로 사용하지 않고, 자원 변화/효과 경로는 unknown으로 반환한다. 대부분의 현재 Lua가 `SetDescription`을 생략하므로 description=0을 효과 번호로 오인하지 않는다. raw description과 서버 후보 순번은 다음 프로토콜 단계에서 보존한다.

## 검증

변경 전 66개 통과. 변경 후 기존 66개 + 신규 4개 = 70개 통과. golden12+합성256의 전체 응답 비교를 유지한다. 신규 검증은 16종 자산 무결성, 변조 실패, 기존 효과 의미 오사용 방지, 미해결 차이 명시다. `tools/audit_isobar.py`는 SQLite 읽기 전용 모드로 설치본을 비교한다. 실제 설치본의 로딩 순서/듀얼은 아직 검증하지 않았다.

재현: `python tools/audit_isobar.py --edopro <설치경로> --output <결과.json>` 및 `python -m unittest discover -s tests -v`.
