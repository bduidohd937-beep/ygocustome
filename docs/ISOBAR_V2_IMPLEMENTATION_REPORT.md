# ISOBAR V2.0 구현 검증 보고서

## 범위

`feat/isobar-v1-edopro`에서 `feat/isobar-v2-implementation` 브랜치를 생성해 V1 파일을 보존한 상태로 카드 16장, 공통 기상 시스템, 카드 DB, 덱 파일과 자동 검증을 갱신했다.

## 구현 상태

- 카드 스크립트: `c210000201.lua` ~ `c210000216.lua` 16개
- 공통 시스템: `isobar.lua`
- 카드 데이터: `cards/cards.json`
- 생성 DB: `expansions/ygocustom.cdb`
- 덱: `decks/isobar-v2.ydk` (메인 40 / 엑스트라 15)
- 자동 검증: `python -m unittest discover -s tests`

## V2.0.2 검증 결과

`c210000212.lua`의 보고된 `<eof> expected near 'end'` 문법 오류를 수정했다. 불필요한 `end`를 제거하고 효과를 단계별 코드로 정리했다. 실제 Lua 파서인 `luaparser`로 `c210000201.lua`~`c210000216.lua` 및 `isobar.lua` 총 17개를 검사했으며 17개 모두 통과했다. 이 검사를 `tests/test_lua_syntax.py`로 자동화했다.

수정된 16개 스크립트와 `isobar.lua`, `ygocustom.cdb`를 `C:\Users\bduid\Games\EDOPro\ProjectIgnis\expansions`에 반영했다. EDOPro 41.0.2 실행과 파일 로딩 확인은 시도했지만, UI 포커스 전환으로 실제 듀얼 재현까지는 완료하지 못했다.

저장소·카드 DB·설치본에서 `아르카`/`Arca` 카드명, 카드 ID, 스크립트가 확인되지 않았다. 따라서 식별 정보가 없는 상태에서 카드 효과를 임의 변경하지 않았다. 해당 카드의 정확한 ID, 스크립트명 또는 원본 스크린샷이 제공되면 `aux.Stringid`와 DB 문자열을 대조할 수 있다.

## V2.0.1 핫픽스 검증 결과

자동 검증은 9개 테스트 모두 통과했다. 카드 ID 연속성, 16장 메타데이터, 스크립트 경로, 속성·종족·종류, 덱 장수와 V2.0.1 핫픽스 가드를 검사한다.

`python tools/build_cdb.py`도 성공했으며 27개 프로젝트 카드가 `ygocustom.cdb`에 생성됐다. 27개는 저장소 전체 카드 수이고 이소바르 V2는 그중 16장이다.

이 환경에는 `lua`와 `luac`가 없었지만 `luaparser`를 설치해 실제 파싱 검사를 수행했다. EDOPro 실행 파일은 실행했으나 자동화 UI 포커스 문제로 실제 듀얼·콤보 재현은 미실행으로 판정한다.

## V2.0 → V2.0.1 변경

- 폭풍경계: `EFFECT_TYPE_ACTIVATE`, 이소바르 몬스터·비폭풍 조건, 발동 시 대상 선택, 같은 턴 묘지 효과 금지 플래그를 적용했다.
- 템페스트 제로: 폭풍/비폭풍 바운스가 `id+1000` 턴 제한을 공유하고 양쪽 효과 모두 메인 페이즈만 허용한다.
- 님버스: `EVENT_BE_MATERIAL`에서 실제 이소바르 엑시즈 몬스터에 무효 효과를 부여하며, 님버스가 소재에서 제거되면 조건이 사라진다.
- 레인: 필드에 이소바르 몬스터 또는 중앙관측소가 있으면 패 특수 소환 가능하도록 수정했다.
- 볼트: 기상 변경을 자신·상대 메인 페이즈로 제한했다.

## 핵심 구현 확인

- 기상 상태는 필드 마법의 플래그로 저장하며 동일 상태 변경은 무시한다.
- 기상 변경은 `EVENT_CUSTOM+210000210`으로 카드 효과에 전달한다.
- 아르젠과 님버스의 묘지 특수 소환은 필드 이탈 시 제외 처리한다.
- 님버스는 `EVENT_BE_MATERIAL`에서 실제 엑시즈 몬스터에 몬스터 효과 무효 효과를 부여한다. 님버스가 소재 그룹에 남아 있을 때만 발동 가능하다.
- 템페스트 제로의 폭풍 상태 효과는 비대상 카드 선택, 비폭풍 상태 효과는 대상 지정으로 분리했다.
- 폭풍경계는 발동 조건에서 이미 폭풍인 경우를 차단한다.
- 중앙관측소는 발동 시 몬스터 서치, 기상 변경 시 엑시즈 존재를 검사해 긴급경보를 세트한다.
