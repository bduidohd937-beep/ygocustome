# DUELMIND V2.2 — Strategic Combo Intelligence

## 변경 요약

- 기준 `7672dc0`에서 `feat/duelmind-v2-2-combo`를 생성했다.
- 기존 합법 행동 제한, Python IPC, Decision Trace, Python 장애 시 fallback을 유지했다.
- `ActivableDescs`의 실제 `long` 효과 설명 값과 `ClientCard.ActionActivateIndex[desc]`를 C#에서 Python으로 전달한다.
- 같은 카드의 복수 효과는 `effect_description + activation_index + effect_profile`로 분리한다. WindBot이 체인 효과 설명을 제공하지 않는 경우 `*_effect_identifier_unavailable`로 명시한다.
- 전략 목표, 검증된 효과 경로, 주요 대안, 예상 자원 변화, 아직 관측되지 않은 실제 결과를 Python 응답과 JSONL에 추가했다.
- 미래 상태를 임의로 생성하지 않는다. 효과 감사로 확인된 경로와 현재 엔진이 제공한 후보만 평가한다.
- `weather`는 Lua Field Spell 플래그가 WindBot `ClientCard` API에 노출되지 않아 `unknown`을 유지한다.

## 기존 문제와 수정 방식

V2.1은 카드 ID와 행동 종류를 중심으로 점수를 계산했기 때문에 같은 카드의 여러 효과를 동일하게 다룰 수 있었다. V2.2는 WindBot의 실제 효과 설명 값과 실행 인덱스를 trace와 IPC payload에 포함하고, 알려진 효과만 검증된 전개 경로와 자원 변화로 연결한다. 설명 값으로 의미를 확정할 수 없는 효과는 점수를 임의로 강화하지 않고 trace에 식별 불가 상태를 남긴다.

## 카드 감사

16장 효과별 조건·코스트·대상·처리·턴 제한·연계는 [ISOBAR_V2_2_EFFECT_AUDIT.md](ISOBAR_V2_2_EFFECT_AUDIT.md)에 기록했다. 감사에는 201~213의 현재 AI 브랜치 카드 구현과 214~216의 V2 카드 구현 브랜치 교차 대조가 사용됐다.

## Decision Trace V2.2

Python 결정 응답에는 다음이 포함된다.

- `effect_identifier`, `effect_description`, `activation_index`
- `strategy_goal`, `chosen_path`
- `major_alternatives`
- `expected_resource_change`
- `actual_result: unobserved_before_execution`
- `plan_change_reason: no_post_action_observation_received`

C# JSONL에는 여기에 턴·페이즈·fallback 원인·실제 WindBot 반환 여부를 추가한다. `action_returned_to_windbot`은 효과 해결 성공을 의미하지 않으며, 후속 상태 관측 어댑터가 없으면 실제 결과는 미확정으로 남는다.
