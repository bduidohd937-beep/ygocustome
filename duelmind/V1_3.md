# DUELMIND V1.3 — Main phase / chain decision bridge

## 구현
- WindBot `GameAI`는 `ExecutorBase`의 중립 virtual hook을 호출한다. 이 구조는 기존 일반 봇의 행동을 변경하지 않으며, WindBot 메인 실행 파일과 ExecutorBase의 어셈블리 참조 방향을 유지한다.
- 이소바르 C# executor는 실제 EDOPro 코어가 제시한 `MainPhase` 목록 중 카드 효과 발동·일반 소환·특수 소환·엑스트라 소환·마법/함정 세트 후보를 추려 Python 서버에 전달한다.
- Python은 유효한 `action_id` 1개를 고르고, C#은 원래 코어 행동의 action index로 돌려준다. 임의의 소환·효과 발동 명령을 생성하지 않는다.
- `OnSelectChain`은 실제 가능한 체인 카드와 선택적 패스 동작을 후보로 넣고 Python 선택을 따른다.
- Python 서버가 꺼져 있거나 응답에 오류가 있으면 이전 WindBot 실행기 우선순위로 복귀한다.
- 기존 `OnSelectCard`, `OnSelectAttacker` Python 연결도 유지한다.

## 한계
- **현재 구현은 실제 플레이 전 검증 전용 V1.3 초안.**
- Python은 실시간 GPT API가 아니라 이소바르 휴리스틱 평가 함수다.
- 코어에서 제시된 행동은 기본적으로 소환/발동이 가능한 액션이지만, 선택적 목표·코스트·엑시즈 소재는 이후 게임 단계에서 별도 WindBot 기본 로직이 처리한다.
- `OnSelectChain`의 optional pass는 첫 장부터 무조건 체인하는 오류를 줄이기 위한 기초 규칙으로, 실제 상대 체인 내용과 효과 유형에 따른 정밀 평가는 다음 단계다.
- EDOPro 실행 중 연결 타임아웃은 한 번의 선택 당 최대 수백 ms를 추가할 수 있다.
- 메인 페이즈에서 `TryDecideMainPhase`가 처리하지 않은 특수 동작은 WindBot 원래 로직이 처리한다.
- 실제 소환-체인-엑시즈 소재-종료까지 완주 테스트는 아직 하지 않았다.

## 설치·실행
1. Actions > `DUELMIND WindBot Windows build` 최신 성공 실행에서 `DUELMIND-Isobar-WindBot-Windows` ZIP 다운로드.
2. EDOPro 종료 후 기존 WindBot 폴더 백업.
3. ZIP 내부 `WindBot` 폴더를 로컬 EDOPro의 WindBot 폴더에 교체 적용. EDOPro 폴더: `C:\Users\bduid\Games\EDOPro\ProjectIgnis`.
4. GitHub 로컬 작업 사본:
   ```powershell
   cd "$HOME\Desktop\ygocustome"
   git fetch origin
   git switch feat/duelmind-v1-3-main-chain
   git pull --ff-only origin feat/duelmind-v1-3-main-chain
   python -m unittest discover -s tests -v
   python duelmind/server.py
   ```
5. PowerShell 창을 열어둔 채 EDOPro 로컬 AI에서 `DUELMIND - Isobar`를 선택.
6. Python 터미널의 `[DUELMIND] selected=...` 로그 및 EDOPro 결과 확인.
