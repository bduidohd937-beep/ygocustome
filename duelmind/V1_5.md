# DUELMIND V1.5 — Isobar Strategy Upgrade

## Why V1.5
The first real EDOPro duel proved the local Python engine was answering, but the bot lost because flat card scores ignored game state. This revision emphasizes combo planning and useful interrupts.

## Implemented
- WindBot passes own face-up Level-4 monster count, own hand and grave card IDs, whether Central Observatory is face-up, and publicly available chain source information to Python.
- Python ranks legal actions using live state: Observatory before opening, Argen starter, hand ignition of Rain/Nova as extenders, Zephyr grave revival, first-turn Stormbastion, second-turn Tempest Zero, and Solar Hawk search.
- Opponent-controlled facedown card IDs are concealed from Python.
- If EDOPro permits battle or ending the turn, those are actual choices. Battle can outrank unhelpful sets.
- Optional self-chain generally passes; opponent chain can provoke a valuable negate when legal.
- Single-card selection prioritizes relevant search cards and publicly visible enemy threats.
- Native WindBot remains a fallback for timeouts and unsupported selection types.

## Diagnostics
The Python console prints chosen action kind, card ID, score, and reason.
The server records bounded local decisions at %TEMP%\duelmind-decisions.jsonl (rotates at 3 MB).
Disable this with the Python server argument --no-decision-log.
The previous native trace remains at %TEMP%\duelmind-windbot.log.

## Automated verification
- python -m unittest discover -s tests -v
- GitHub Actions EDOPro starter validation: Python tests, Lua syntax, custom CDB check
- GitHub Actions DUELMIND WindBot Windows build: .NET8 Windows binary
- These prove static behavior and buildability, NOT a better win rate in real duels.

## Quick deployment
1. Exit EDOPro, back up its WindBot directory and replace it with the newest successful V1.5 build artifact.
2. In the Git repository located at Desktop/ygocustome:
   - git fetch origin
   - git switch feat/duelmind-v1-5-strategy
   - git pull --ff-only origin feat/duelmind-v1-5-strategy
   - python -m unittest discover -s tests -v
   - python duelmind/server.py
3. Leave the Python server open. Run EDOPro and select DUELMIND - Isobar under local AI.
4. Share your duel replay and the two local DUELMIND logs to identify further strategic errors.

## Still outstanding
