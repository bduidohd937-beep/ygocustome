## 중요한 충돌
1. **카운터**: 7월 초기 설정은 필드 마법 「영겁의 윤회」에 윤회 카운터를 쌓는 구조. 이후 사용자 의사로 윤회 카운터 폐기. V1 DB에서 초기 설정을 최신 규칙으로 단정하면 안 됨.
2. **메인 카드 목록**: 초기 제1·64·108순환과 11월 요약의 제0·17·31·43·62·82·128·250·666·999순환이 다르다.
3. **싱크로 레벨**: 11월 요약의 제999순환 싱크로는 **레벨 8**, 제666순환 싱크로는 **레벨 10**, 최종 제0순환은 **레벨 12**.
4. **카드명**: 윤회의 순환/윤회기사의 순환 등 명칭 변경이 완전히 확정되지 않음.
5. **영겁의 윤회**: 초기 설정 필드 마법. 최근 개정 텍스트는 **윤회의 성당**으로 기술되므로 두 카드가 같은 카드인지 별개인지 미확인.
6. **윤회종언**: 묘지의 자기 자신을 제외하면서 다시 세트한다는 개정 효과에는 규칙 충돌이 있음.
